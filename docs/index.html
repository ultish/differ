KSP writes the comparator. You keep the bits and the events.

Annotate the fields you care about. The processor emits a *Differ that compares two values of the same type. hasChanged is a bit test. changes holds only what moved, keyed by id, never by list position.

What you write

// same type on both sides
@Differ
data class Pet(
  val id: String,
  @Tracked val name: String,
  @Tracked(captureValues = false)
  val notes: String,
  @Tracked val nickname: String?,
  @TrackedNested val owner: Person,
  @TrackedNested val vet: Person?,
  @TrackedList val toys: Set<Toy>,
  @TrackedList val walks: List<Walk>,
  @TrackedMap val tricks: Map<String, Trick>,
  @TrackedMap val tags: Map<String, String>,
)
val diff = PetDiffer.diff(old, new)
if (!diff.hasChanged) return
if (diff.hasName) { /* bit test */ }

for (change in diff.changes) {
  when (change) {
    is PetChange.ToysName -> {
      change.id
      change.old
      change.new
    }
    is PetChange.Vet -> change.new
    else -> {}
  }
}

diff.toys["t1"]?.name?.new
diff.tags["color"]?.value?.new

Child types do not take @Differ. Their tagged fields fold into PetDiffer. A rename of a tagged property fails the build. A new untagged field is invisible.

Rules that matter

Lists, sets, and maps match by id (or map key), never by order. TreeSet and TreeMap count. null list or map is empty. Optional nested objects record presence. Both null is unchanged. One null is a single event with the whole object. Primitive arrays are not keyed collections. Mark them @Tracked and compare the whole array.
